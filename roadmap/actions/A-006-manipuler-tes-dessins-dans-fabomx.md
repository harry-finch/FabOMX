Où : branche r-002-transformer. Lancer « cd ui && npm install && npm run wasm && npm run dev », puis ouvrir http://localhost:5177 (bouton « Version web » de FabBoard).
Quoi faire : importer un de tes dessins, puis avec Déplacer (M) le glisser, avec Tourner (R) le faire tourner (Maj : par 15°), avec Mettre à l'échelle (S) tirer une poignée de coin ; essayer les flèches du clavier, les miroirs, ±90°, le cadenas, et ⌘Z.
Ce qu'on regarde : les gestes sont-ils naturels ? Le point de référence (croix bleue) est-il facile à comprendre ?
Répondre : « les gestes conviennent », ou ce qui gêne.
