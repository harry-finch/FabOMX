Où : l'application installée.
Quoi faire : parcourir les menus FabOMX, Fichier, Édition, Présentation, Fenêtre, Aide ; importer trois fichiers puis ouvrir Fichier > Importer un fichier récent ; quitter, relancer, vérifier la liste ; déplacer un des fichiers dans le Finder et le rouvrir depuis la liste ; tester Édition > Annuler sur une transformation, puis ⌘Z dans un champ numérique ; passer l'application en EN et regarder les menus.
Ce qu'on regarde : la liste des récents, le message pour un fichier disparu, Annuler qui n'agit qu'une fois et sur la bonne chose, les menus traduits.
Répondre : « les menus conviennent », ou ce qui ne va pas.

## Réponse

Validé : ça marche très bien.
