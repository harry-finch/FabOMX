Où : branche r-003-interface. Lancer « cd ui && npm install && npm run wasm && npm run dev », puis ouvrir http://localhost:5177 (ou le bouton « Version web » de FabBoard).
Quoi faire : regarder la fenêtre en thème sombre et clair, à pleine largeur puis fenêtre réduite vers 1100 px ; zoomer à la molette, déplacer la vue (outil Main, ou espace + glisser), appuyer sur F.
Ce qu'on regarde : palette d'outils à gauche, plateau 305 × 305 mm au centre avec l'origine en bas à gauche, paramètres à droite, coordonnées et zoom dans la barre d'état.
Répondre : « la disposition convient », ou ce qui gêne.
