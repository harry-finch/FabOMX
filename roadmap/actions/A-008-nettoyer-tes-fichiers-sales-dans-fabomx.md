Où : branche r-004-nettoyer. Lancer « cd ui && npm install && npm run wasm && npm run dev », puis ouvrir http://localhost:5177 (bouton « Version web » de FabBoard).
Quoi faire : importer un ou deux de tes fichiers « sales » (contours mal fermés, doublons), sélectionner le dessin, prendre l'outil Nettoyer (C) ; régler l'écart max si besoin, regarder le bilan, cliquer Nettoyer. Essayer aussi « Nettoyer à l'import » dans le dialogue d'import.
Ce qu'on regarde : le résultat est-il bon pour la découpe ? Ce qui reste ouvert est-il bien dit ?
Répondre : « le nettoyage convient », ou, par fichier, ce qui ne va pas (joindre le fichier si possible).
