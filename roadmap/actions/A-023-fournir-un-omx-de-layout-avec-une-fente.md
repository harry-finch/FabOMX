---

Pour confirmer comment LAYOUT écrit une fente (coupe sur la ligne, sans décalage), j'ai besoin d'un exemple : je suppose OffsetSide = 0, sans preuve.

Dans LAYOUT, dessine une plaque avec une fente (un trait ouvert coupé sur la ligne). Si possible, ajoute un trou carré et une petite pièce posée dans un grand trou. Génère le parcours et dépose le DXF et l'OMX dans `omx/`.

Réponds avec le nom des fichiers déposés.
