Où : `dist-desktop/FabOMX.app` (à lancer sur place) ou la version web (`cd ui && npm run dev`, http://localhost:5177).

Gestes : importe une plaque avec un trou et une fente (ou l'un de tes dessins), outil Parcours (P), « Exporter l'OMX ». Dans l'application Mac, le dialogue Enregistrer s'ouvre. Ouvre le fichier dans MAKE (ou LAYOUT).

À observer : le fichier s'ouvre sans erreur ; le parcours, l'ordre, les amorces et les arcs sont ceux de FabOMX ; les côtés de coupe (décalage de la saignée) sont du bon côté ; les dimensions sont justes ; le départ est là où est la buse.

Réponds « ça marche », ou ce que MAKE dit ou montre de travers.

## Réponse

Ça marche.
